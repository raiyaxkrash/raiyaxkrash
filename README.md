### О себе

Создаю быстрые, легковесные нативные утилиты для **Windows 10/11** на **Rust + Tauri 2 + Win32 / WinRT** — без тяжелого Electron, с упором на 60 FPS, минимальный вес и чистый интерфейс. Также разрабатываю моды для Minecraft и инструменты автоматизации на Python.
